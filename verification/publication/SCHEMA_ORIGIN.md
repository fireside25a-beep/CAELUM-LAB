# Citation schema provenance

`cff-schema-1.2.0.json` is the unchanged Citation File Format 1.2.0 schema from the Citation File Format project. Source: https://github.com/citation-file-format/citation-file-format/blob/1.2.0/schema.json . Its CC BY 4.0 license is reproduced in `CFF_SCHEMA_LICENSE.txt`. The schema is used only for publication-metadata validation, not by CAELUM's scientific runtime. No endorsement is implied.
